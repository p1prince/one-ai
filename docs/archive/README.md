# Historical project records

This folder preserves the pre-release development record for context. These files are not the active roadmap or handoff.

- `DEVELOPMENT_TRACKER_PRE_RELEASE.md`: the detailed app-construction tracker as it stood when the owner accepted the current app baseline.
- `HANDOFF_PROMPT_PRE_RELEASE.md`: the superseded handoff prompt, retained so earlier decisions and instructions remain traceable.

Use the root `DEVELOPMENT_PLAN.md` and `DEVELOPMENT_TRACKER.md` for current release work, together with `docs/PROJECT_CONTINUATION_RULES.md` and `docs/DECISIONS.md`.

The former "ONE AI Official Open-Shell Development Plan" is referenced in historical records but was not present as a standalone tracked file in the inspected repository tree at the release-roadmap baseline. No missing source document has been fabricated or silently deleted.
